# Round 2 (policy iteration): the round-1 CF agent as the continuation policy -- negative, below the round-1 futures

User's request (2026-09-19): take the CF agent that "already learned a bit of
detour", use it as the new continuation policy, regenerate the branch replay,
retrain critic and actor.  Design sealed in `manifest.json` before training:
per lineage s in {0, 1, 2} the round-1 CF agent `CF/seed_s/final.pkl` (no
selection of a best seed) continues the branches at the SAME anchors with the
SAME hazard seeds (`HAZARD_SEED0 + anchor_id`), and three arms are trained
from that agent with fresh paired critics (same critic / actor streams, losses,
bc 0.05, lr, 30,000 updates): O (recorded futures), CF (regenerated futures),
CFold (the round-1 futures, generated by the start agent -- separates
"regenerated futures" from "second actor phase").  Evaluation on the same 300
episodes (seed 3909, mode).  Nodes 30043 / 30125 / 30016 (lineages 0 / 1 / 2);
checkpoints stay on the nodes.  Results in `REPORT.md`, `results.json`.

## Reading

- The improved agent as the continuation policy does not create the missing
  futures: the query is the logged torque, and one logged shortcut torque is
  enough to keep every continuation agent on the shortcut.  The only detour
  futures remain those of the 5 % logged-detour anchors; regeneration changes
  their quality (slower, more timeouts from the start region) and the
  shortcut anchors' deaths, not the route content.
- The actor's detour rate is not a stable property of the agent: recorded
  futures return it to the start level within 30,000 updates (O2: 0.01), the
  round-1 futures hold it at 0.12-0.21 (CFold2; from 0.11 / 0.17 / 0.50 --
  the 0.50 of round-1 seed 2 was a transient), and a critic preference of
  +1.5-1.9 nats at the reset rows is not enough to hold it against bc 0.05 at
  all (CF2 s1 / s2).  This is the tie of diag_traj section 9b seen from the
  other side: the mode sits where the update budget and the critic margin put
  it, and the margin needed for a stable detour is larger than what these
  futures give.
- Policy iteration in this form (same anchors, logged query torque, one
  branch per anchor) is therefore not the in-boundary lever it was proposed
  as: it neither adds route coverage nor strengthens the critic margin.  A
  further round from the CF2 agents would start from the start behaviour.

Nothing was selected after the evaluation; all three lineages are reported.
