# Predeclared PointMaze oracle-motion CRL training pilot

This bounded pilot starts at commit `529ea0f2463d93b20ef32298bfc4ac5ccd7773f3`. It asks whether counterfactual episode data improve the frozen starting actor in the native PointMaze environment when alive-position error is removed with the already verified native-motion helper. It is an exploratory downstream training test, not evidence for learned ETT motion, observational identification, pessimistic optimization, or AntMaze.

## Frozen transition and learner semantics

Generated paths replace only alive-position movement with the bit-exact helper sealed in `outputs/pointmaze_oracle_alive_motion_20260914_v1`. At each path's current F4 state, the unchanged historical nominal samples advice and the current actor samples the queried action. Native Gaussian action noise (standard deviation 0.01), clipping, ten float64 substeps, sequential X/Y collision checks, and float32 F4 emission are retained. Repaired head 0 is used for training seed 0 and repaired head 1 for seed 1. The native hazard support, onset RNG, fatal incoming movement, irreversible failure, frozen post-failure XY, F4 shift, and zero failed reward remain fixed. Native hidden bits, death, termination, and reward never determine generated failure or enter actor observations.

The existing full-F4 Monte Carlo Contrastive RL learner is unchanged. It restores the complete step-150,000 learner state: actor, critic, target critic, actor Adam, and critic Adam. Binary NCE uses a batch-by-batch positive diagonal and in-batch negative goals. Each replay anchor uses a strictly later achieved full-F4 state from the same finite episode, sampled with probability proportional to `0.95^(j-i)`. The actor maximizes its diagonal critic logit with `random_goals=0.5`, behavior cloning coefficient 0.5, and entropy coefficient zero. Both learning rates are 0.0003, batch size is 256, target update tau is 0.005, and there is no separate critic warm-up because the restored critic and optimizers are already trained. Reward and discount fields are unused by this Monte Carlo loss; arbitrary logits are not interpreted as calibrated returns.

Generated episodes retain their complete remaining horizon. A failed path remains in the episode as the native observation contract requires. Consequently, post-failure achieved observations can remain legitimate hindsight goals for their own frozen hazard position, just as absorbing tails already present in the offline data do. They are never relabeled as the commanded task goal: all fatal positions lie outside the task reward radius. The replay audit will verify `j>i`, finite valid indices, no padding, zero generated reward after failure, frozen XY, correct F4 shift, and zero task-goal positives among failed future states. No hidden failure flag is appended to the actor's eight-dimensional observation.

## Controlled training

Condition A is the unchanged starting actor and is evaluated once. For each training seed 0 and 1, B is offline-only continuation and C is oracle-augmented continuation. B and C begin from byte-identical complete learner state and RNG within seed. Both receive exactly 1,000 joint critic/actor updates and identical full offline draws and batch permutations. C uses the established 10% replacement convention: 25 or 26 rows per 256-row batch are replaced so that exactly 25,600 of 256,000 rows are generated. B keeps all 256 offline rows. This is a data replacement, not extra updates.

C refreshes its generated replay before updates 0, 250, 500, and 750 using its current stochastic actor. At each refresh, 32 training episodes are drawn at each root time 0, 10, 25, and 40 from the established 5,940-episode continuation partition. One coherent path is generated from every root for the full remaining horizon 50, 40, 25, or 10. Only the current refresh's 128 paths are retained. Offline observations contain no full-precision historical physical coordinate or death bit, so each generated root starts alive at its emitted XY promoted to float64; higher physical precision is preserved from its first oracle transition onward. Evaluation seeds and trajectories are not training roots.

The fixed budget is four trained policies, 4,000 critic updates, 4,000 actor updates, 1,024 generated training paths, and 32,000 generated training transition slots. Runtime is capped at 1,800 seconds. There is no sweep, early stopping, extension, checkpoint selection, or ETT/head update.

## Final evaluation and analysis

All five policies (A, B0, C0, B1, C1) are sealed before outcomes. Each is evaluated on the same 200 fresh native reset seeds for 50 steps, with shared stochastic actor-noise keys. These seeds are disjoint from all training data and earlier development/evaluation seeds. Total new native evaluation is exactly 1,000 episodes and 50,000 steps. The primary outcome is raw discounted native task return. Failure, native reward occurrence, strict physical-distance success below 0.5, first hazardous landing, conditional first-entry time, and at-risk hazardous opportunities are secondary/explanatory outcomes.

For each head/seed, A, B, and C also receive 256 independent full oracle-model paths from reset START under common model streams. This totals 1,536 predictive paths and 76,800 slots. Together with training generation, the hard model cap is 2,560 paths and 108,800 slots. Predictive paths are not native episodes and their bootstrap intervals are labeled separately.

Uncertainty uses 2,000 paired episode bootstrap replicates over the 200 shared native seed units. Each seed reports C-A, C-B, and B-A. Model uncertainty resamples its 256 paired predictive paths separately. Evidence for added counterfactual benefit requires native C return improvement over both A and B; improvement over A alone is insufficient. With two training seeds, results remain conditional exploratory evidence rather than across-seed proof. Final checkpoints are selected solely by the 1,000-update budget.
