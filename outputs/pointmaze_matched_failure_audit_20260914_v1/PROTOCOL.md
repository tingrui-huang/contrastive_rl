## Replay and matched contexts

Replay all 48 saved native episodes from their saved environment seeds and execute their saved actor actions for all 50 steps. Before every action, query the original windy teacher on that exact native snapshot. Teacher RNG seed is `14,140,000 + episode`, separate from the environment RNG. One teacher and one memo live for the whole episode, preserving the episode-level 0.05 force-safe draw, route memo, per-step active-bit reaction, clipping, and the original rule that Gaussian noise with standard deviation 0.15 is applied only when the unnoised advice is nonzero. Verify before using a row that the query leaves native XY, F4 frames, goal, hidden bits, death mode, auto-resampling flag, and environment RNG byte-equivalent; then require exact saved observation, successor, death-state, and reward replay agreement.

Save every replay row as `(episode, time, s, xb_shadow, xq_saved_actor, y_real, dead_before, dead_after, onset, reward)`, plus audit-only shadow mode and hidden bits. Advice is a newly sampled, same-hidden-situation shadow query, not recovered historical advice and not an independent nominal draw. Only the 1,165 expected alive-before rows are evaluated. The teacher's privilege is restricted to advice construction and replay verification; no actor or nominal model is queried.

## Matched checks

For each alive context `c=(s, xb_shadow, xq_saved_actor)`, call the actual candidate sampler in its declared order `(theta, state, action=xq_saved_actor, xb=xb_shadow, key, count=64)`. Position seeds use `16,140,000 + 100,000 * position_seed + batch_start`; each position array is reused unchanged across both heads. Failure features retain their trained order: standardized F4, raw shadow advice, raw saved actor action, and raw next-XY displacement.

Check A evaluates both frozen heads at the real successor. For all rows, input-defined approach/inside/right-exit/elsewhere groups, and actual hazardous/nonhazardous landings, report counts, observed and predicted onset rates, calibration-in-the-large, Brier score, log loss, fixed-width calibration bins, and whole-episode uncertainty.

Check B compares one row-level real outcome with each row's 64-draw predictive distribution. Events are native hazardous landing; hazard entry from a currently nonhazardous state; remaining in and exiting hazard from a currently hazardous state; positive horizontal displacement toward the right-hand corridor exit; and stationarity under the inherited Euclidean `1e-7` threshold. Also report expected versus actual horizontal displacement and descriptive predictive quantiles. Samples are integration draws, never 64 independent native labels.

Check C computes `q(c)=mean_k h(c,y_k)`, and separately `q_haz=mean_k I(hazard(y_k))h(c,y_k)` and `q_nonhaz=mean_k I(not hazard(y_k))h(c,y_k)`. Score these against onset, onset with an actually hazardous landing, and onset with an actually nonhazardous landing, respectively, within the same input-defined groups. Report generated hazard/head coupling covariance, but do not treat an actual-outcome hazard stratum as conditioning the marginalized predictor on a generated hazardous landing. No support mask is applied; impossible outside-hazard native onsets are reported separately.

Input groups are frozen in `config.json`: left approach is current XY in `[2,3) x [3,4)`, inside hazard is `[3,6) x [3,4)`, right exit is `[6,7) x [3,4)`, and elsewhere is the complement. Native legality uses the existing inclusive-bound and clipped floor-cell convention. Group definitions use all outcomes available in the group.

## Exposure and uncertainty

Using only saved native and death-disabled baseline trajectories, report the probability, conditional time, mean XY, and swamp-cell distribution of the first hazardous landing. First landing precedes the native death check and is not death-censored. Later native exposure is the number of hazardous landings with `dead_before=false`, including the fatal opportunity. Model at-risk exposure is integrated on saved baseline paths with survival-before-transition weights `S_t=product_{j<t}(1-h_j)` for each frozen head. It is explicitly onset-law-dependent and cannot independently prove a position defect. No independent Bernoulli wrapper is introduced.

All uncertainty uses 2,000 predeclared whole-episode bootstrap replicates with seed 17,140,000. Rows and the 64 predictive draws stay clustered within their original native episode/root; no model draw is counted as additional native evidence. The older four-query paired evaluation is not used as new evidence, so its four-query dependence is not re-entered; inspected historical summaries remain identified as historical.

## Budgets and decision rule

Charge 2,400 native replay steps before replay, at most 307,200 planned position successors before sampling (`48*50*64*2`; actual use is lower after the alive restriction), and zero training updates. Hard caps are 2,400 native steps and 310,000 position successors. Reuse completed stage artifacts after interruption; never silently repeat a charged collection.

Interpretation is fixed: clear real-successor overprediction prioritizes head calibration/conditioning; credible A with excessive entry/residence or poor exit in B prioritizes alive-conditional position dynamics; acceptable separate checks with failed C prioritizes generated-successor coupling; passing real-context checks with autonomous mismatch leaves generated-state and historical nominal-mixture mismatch unresolved. Mixed or sparse evidence remains unidentified. Any correction must retain irreversible absorption and fatal-transition movement. Current 48 episodes are exploratory reuse; a selected modification requires fresh complete confirmation episodes.
