# Sealed PointMaze matched-fork diagnostic

## Objective and scope

This bounded diagnostic asks where a geometrically valid lower-route decision fails to become useful behavior for the final `C_s1` actor. It is pinned to reviewed commit `84d378f3b610d13b77840b0c8a96166f760d7b96`. It does not train a new policy, rerun the A/B/C pilot, search checkpoints, alter the learner, or touch AntMaze.

The frozen configuration is the final C1 actor and its own saved critic, repaired failure head 1, historical nominal policy, exact native alive-motion helper, fixed F4 task goal, native reward, discount 0.95, horizon 50, and the native time remaining at each root.

## Root selection sealed before intervention outcomes

The source is the saved `C_s1_native.npz` evaluation array. Episodes are inspected in ascending saved array index. For each episode, select its first transition-time state satisfying all of:

1. current XY has `1 <= x < 2` and `3 <= y < 4`;
2. the saved actor is alive before the action;
3. no earlier saved transition landed in the hazardous upper corridor;
4. at least three native steps remain;
5. the zero-noise exact movement helper sends action `[0,-1]` to cell `(1,2)` and action `[1,0]` to cell `(2,3)`.

Take the first 16 distinct qualifying episodes. If fewer qualify, use all and report that limitation. No critic score, saved episode outcome, candidate continuation, or intervention return enters selection.

Every root is regenerated by resetting a native environment with its saved reset seed and replaying the saved C1 actions from time zero. The regenerated physical XY, full F4 state, alive status, and time must exactly match the saved trace. Arbitrary offline intermediate observations are prohibited.

## Hidden-state timing and continuation interface

The native swamp bits visible only to the audit govern the current step's death check and are resampled after every step. A focused check must show that an explicit schedule reproduces the native automatic RNG order: Gaussian action noise first, current bits for the death check, then three new Bernoulli bits for the next step. A lethal/clear pair at the same hazard landing must confirm that current bits, not post-step bits, determine onset.

Repeated native continuations preserve the naturally reached root bits for the forced first action. Thereafter they draw fresh Bernoulli bits after every step; bits are never frozen. The reusable scheduled-native interface calls the real native environment with explicit action noise and post-step bits. Native hidden bits are saved for evaluation audit only and never enter the C1 actor, critic, nominal policy, or learned failure head.

## Primary matched intervention

At every root compare fixed geometry actions:

- downward exit: `[0,-1]`;
- rightward shortcut exit: `[1,0]`.

The movement helper records each exact candidate action and its noiseless physical displacement. Candidate actions are not optimized or selected by the critic or returns.

For each root, action, and backend, run exactly 64 continuations. Force the candidate for one step, then resume the same frozen stochastic C1 actor for the remaining native horizon. The native backend uses the native environment. The model backend uses exact alive motion, sampled historical nominal advice, repaired head 1, support gating, fatal incoming motion, irreversible absorption, and zero reward after failure.

The initial design therefore contains 16 x 2 x 2 x 64 = 4,096 continuation paths. Path length is `50-root_time`, never a reset 50-step extension.

Actor Gaussian innovations and physical motion noise are paired across action alternatives and across backends because they have the same meaning. Future native swamp bits are paired only between native action alternatives. Model nominal draws and onset uniforms are paired only between model action alternatives. Native bits are never paired with model onset uniforms.

## Outcomes and uncertainty

Save full observable/physical traces, actions, motion noise, native bits, nominal advice, failure probabilities, onset uniforms, rewards, failures, hazard landings, and validity masks. Report continuation and whole-episode discounted return, reward occurrence, strict radius-0.5 success, failure, at-risk hazard exposure, and actual lower-route entry.

The predictive 64 paths integrate randomness within a root; they are not 1,024 or 2,048 independent source episodes. First average paired paths within each root. Uncertainty is then a paired bootstrap over the distinct root contexts using 5,000 weights sealed before outcomes. Conditional predictive Monte Carlo standard errors are reported separately.

The C1 critic score is computed at the identical saved root F4, exact candidate action, and stationary F4 task goal. It is an action-ranking logit, not a calibrated return.

## Single conditional follow-up

Preference means a lower endpoint above zero for the paired 95% root-bootstrap interval.

- Branch A: if native down-minus-right return is not clearly positive, inspect reversal after the one-step deviation and run only the predeclared three-action prefix `[down, down, right]`, then resume C1. Compare it with the already generated rightward arm using another 64 paths per root/backend. A prefix value is not compared with the one-step critic score as an estimation test.
- Branch B: if native clearly favors down but the model does not, use saved traces only to localize movement, nominal-conditioned failure, or later behavior. No training.
- Branch C: if native and model clearly favor down but the critic does not, audit saved replay/goal/continuation coverage only. No retraining.
- Branch D: if native, model, and critic clearly favor down, run at most 10 frozen-critic actor updates from identical C1 initialization for the existing full objective, its value term alone, and its BC term alone, on one predeclared common saved offline batch. Measure root action distributions and noiseless feasible exits. Do not claim improved continuation behavior without a separately capped native validation of at most 512 paths.

Only the selected branch may execute. An interval containing zero means "no advantage established", not action equivalence. No budget is silently enlarged for precision.

## Caps and exclusions

Primary caps are 4,096 paths, 2,048 paths per backend, and 102,400 transitions per backend. Root regeneration/timing checks have a separate 128-native-step cap. Branch A adds at most 2,048 paths and 51,200 transitions per backend. Branch D has at most 10 updates per probe and no automatic native validation. Total wall-clock cap is 7,200 seconds.

No goal proportions, goal representation, NCE loss, BC coefficient, actor architecture, motion parameters, or checkpoints change. This diagnostic cannot validate learned ETT motion, observational identification, or the original worst-case loss. Any eventual modification still requires new complete development episodes and later confirmation episodes.
